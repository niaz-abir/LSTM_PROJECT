# LSTM Deep Learning Projects

A collection of hands-on projects developed using **Long Short-Term Memory (LSTM)** networks with Python and PyTorch. These projects demonstrate how LSTM architectures learn sequential patterns from text data and perform tasks such as sentiment classification and next-word prediction.

## 📌 Projects

### 1. Movie Review Sentiment Analysis Using LSTM

A binary text classification project that uses an LSTM neural network to analyze movie reviews and classify their sentiment as **Positive** or **Negative**.

**Key Features:**
- Movie review dataset using NLTK.
- Text preprocessing and tokenization.
- Vocabulary creation and numerical encoding.
- Sequence padding and preparation.
- Word Embedding layer.
- LSTM-based neural network architecture.
- Model training using CrossEntropyLoss and Adam optimizer.
- Sentiment prediction on new reviews.

**Example:**

| Input Review | Predicted Sentiment |
|---|---|
| This movie was absolutely fantastic and inspiring. | Positive |
| The storyline was weak and the acting was disappointing. | Negative |

### 2. Next Word Prediction Using LSTM

A sequence-based deep learning project that uses an LSTM network to predict the most likely next word based on a given sequence of previous words.

**Key Features:**
- Text preprocessing and tokenization.
- Vocabulary creation and numerical encoding.
- Sequential input preparation.
- LSTM-based neural network architecture.
- Model training on text sequences.
- Next-word prediction based on contextual word patterns.

**Example:**

| Input Text | Predicted Next Word |
|---|---|
| Artificial intelligence is transforming | technology |
| The future of deep learning | research |
| Machine learning models can | predict |
